# 迭代二实现与使用

## 算法与入口

分类：逻辑回归、CART。聚类：KMeans、DBSCAN。降维：截断 SVD、CUR。六种算法各有独立 DeepSeek function calling 工具，未指定算法时使用 compare_analysis 顺序执行对应两种。工具描述分别说明前端展示内容。

先完成迭代一的清洗和清洗后五维评估，也可直接运行原有统一流程。分析输入必须匹配清洗数据版本、清洗规则版本和评估中的时间边界。缺失或冲突时明确失败，不用原始文件或示例结果替代。

可直接提问：“比较两种算法对用户 1、电影 1 的高分预测”“用两种聚类算法分析用户偏好”“比较 SVD 和 CUR 的二维表示”。这些是调用示例，不预设结果。

## 时间约束

训练期为评分时间不晚于 T1，验证期为 T1 之后、不晚于 T2，测试期为 T2 之后。边界取匹配的清洗后评估报告，不重新按分析结果调整。

分类训练样本只使用严格早于该事件的评分历史；同一时间戳先生成整批特征再更新统计。验证、测试和目标预测统一使用 T1 冻结历史，防止未来评分泄漏。

参数与阈值按验证期选择。测试指标在候选配置确定后计算。相同配置复用已登记结果；显式 predict/lookup 不会偷偷训练缺失模型。

## 分类设计

目标为评分至少 4 分。特征是年龄独热、电影类型多热、用户与电影的历史均分及评分数；均分以历史总体均分平滑，计数取对数。编码词表及数值标准化仅由训练期拟合。

逻辑回归默认验证正则强度倒数 0.1、1、10。CART 默认验证最大深度 4、8、12 与叶节点最少样本 10、50 的组合。以验证期精确率召回率曲线面积优先、综合表现 F1 次之选择；判定阈值取验证期最佳 F1 对应阈值，也可显式指定。

记录准确率、识别率、F1、ROC 曲线面积和精确率召回率曲线面积。单一类别、空测试期等指标不适用情况给出原因。概率未经校准；已知但训练期无历史的 ID 使用先验并标注冷启动，未知 ID 明确失败。

## 画像与聚类

使用训练期高分电影的 18 类类型分布构造用户画像。一部多类型电影按类型数等分一次贡献，再按用户总贡献归一化。默认至少 5 条训练期评分且存在高分信号才参与分组；不满足者记录原因，不删除用户。

KMeans 默认候选群体数 3、5、8，初始化 10 次。DBSCAN 默认候选邻域半径 0.1、0.15、0.25，密度样本数 5、10；候选按实际样本数限制。随机种子默认 42，可由工具参数调整。

所有候选只拟合训练期画像。验证期以已知训练用户的后续高分类型交叉熵选择配置；群体分布由训练期画像均值形成，类型概率加 0.01 平滑，噪声使用训练期总体分布回退，不丢弃难例。最终再计算测试期损失与覆盖率。没有验证事件时明确记录不可评价，并采用固定候选顺序及覆盖率打破平局，不声称已完成验证。

同时记录轮廓系数、群体分离指数、群体数、覆盖率及 DBSCAN 噪声比例。轮廓系数最多固定抽样 2000 人；只有一个群体或全为噪声时显示无法计算。群体以主要类型分布和训练期高分次数最多的电影解释，不推断用户性格。

## 降维与对照

SVD 使用不中心化的截断分解，保留用户行数。CUR 按训练期行列能量加权、无放回采样，使用伪逆连接采样行列；用户坐标取选中类型列，因此维数确实等于选中列数，仍覆盖全部合格用户。默认采样用户数为输出维数的两倍，受可用用户数限制。

可指定输出维数或信息保留目标，二者互斥。信息保留定义为一减去相对平方重建误差。CUR 达不到目标时返回明确状态，不将采样行数冒充输出维数；零向量和秩不足保留并说明。

原始画像先按验证期选择聚类配置，再对原始与降维表示使用同一算法、参数和随机种子。原始图以原始画像的二维 SVD 坐标展示，颜色取原始空间聚类；降维图取降维坐标前两列，颜色取降维后聚类。一维输出的纵轴仅为显示常数。

同时提供各空间内部指标、共同非噪声用户在原始空间的指标与分组一致性，防止把改变距离后的轮廓系数提升直接当成有效改进。记录降维与聚类对照用时、矩阵大小、模型大小及进程峰值内存；数据只有 18 维，不承诺压缩一定更好。

## 页面与报告

新增结果组件位于 src/features/analysis，独立于 App.tsx。分类使用概率条和验证／测试表，聚类使用归属、群体摘要和代表内容，降维使用信息保留摘要、真实散点图和对照表。全部使用中文字段和可读版本，不在主卡片堆原始公式、哈希或模型内部数据。

参数、切分、版本、限制可展开查看。预测、画像、群体归属和坐标使用实际产物分页。模型文件不允许从结果下载接口直接访问。

本轮新结果及新的目标预测自动汇入 Markdown 报告；普通历史读取不生成报告，用户明确请求可重建历史报告。下载入口统一放在本轮对话下方。降维提供坐标、对照表和 SVG，聚类保留群体与画像结果，分类预测样例在页面查看，评价结果进入报告。

## 运行环境与持久化

开发环境安装 requirements-analysis.txt。设置中可选本机或 SSH 分析主机，并可检查环境。分析主机与 Hadoop 主机可不同；源清洗文件缺少本地副本时，按清洗任务保存的 Hadoop 连接获取。

本机优先使用随应用发布的独立分析程序，也可指定 Python 可执行路径。SSH 使用免密登录与远端 Python，远端需安装相同分析依赖；当前 SSH 命令适用于常见 POSIX SSH 主机。Windows 客户端、本机 Python 和打包入口没有依赖 Linux shell 命令。

分析工作进程通过 JSON Lines 返回进度和结果。停止对话会终止本机工作进程或 SSH 会话；远端进程监视父连接标准输入，连接关闭即退出。远端临时目录在结束后尝试清理。

应用数据目录下 analysis/datasets 保存校验后的建模视图及排除记录，analysis/assets 保存模型、画像、分组、坐标、配置和指标。发布标记最后写入；失败或中断的临时目录不作为已完成结果。数据集身份包含清洗任务、内容版本、规则版本和时间边界，版本变化不会复用旧配置。

已登记分析资产为后续迭代独立保留；删除对话会删除该对话的消息、任务及下载副本，不删除共享分析资产和共享数据源。历史结果显式 model_id 复用，不允许同时偷偷修改模型参数或用户集合。

Release 工作流分别在 Windows、Linux 构建独立分析运行程序，执行六算法与登记复用协议检查，再打包应用；终端用户不必额外安装 scikit-learn。Hadoop 仍按原有设置连接。

## 验证范围

本次本机验证：前端生产构建、Rust 单元测试、Python 规则与分析测试；现有真实清洗数据六算法运行；独立 Linux 分析程序六算法及复用检查；真实结果的前端渲染和分页读取。

真实清洗数据切分为训练 697006、验证 149357、测试 149358 条。该数据包含项目之前的清洗与修正，不作为官方数据集基准。测试期逻辑回归 F1 为 0.7398，CART 为 0.7347；二维 SVD、CUR 重建信息保留分别约 80.28%、64.31%。这些是当前切分和配置下的结果，不作为最优性结论。

真实数据验证在临时目录执行，没有写入现有对话或替换共享数据。付费 DeepSeek 在线调用、真实 SSH 分析主机和 Windows 安装包运行尚未实测；Windows 打包由 CI 执行。
